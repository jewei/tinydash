# Features

What TinyDash does, for users and for anyone changing it. Keep this page true: update it in the same change as the behavior.

## Open and navigate

Press **Control+Shift+Space** (change it in Settings > General) from any app. The shortcut needs Control, Alt, Command (Win or Super), or a function key, or is Shift+Space, so it never blocks typing. On macOS, a letter or sign in the shortcut is stored by its key position, so on a layout other than US, Settings may name a different key than the one pressed. On Windows and Linux, the recorder ignores signs, which each layout puts on different keys, and keys that Windows or Linux would register as another key, such as numpad Enter. A key typed with AltGr is never a shortcut. The modifier shows as Win on Windows and Super on Linux. Where the global shortcut does not work, such as on Wayland, bind a desktop shortcut to `tinydash`: running it again toggles the launcher. The shortcut hides the launcher only while you are in it; when the launcher is open behind another app, the shortcut brings it to the front. A saved shortcut that would block typing, such as a plain letter in a hand-edited `settings.json`, gives way to Control+Shift+Space at startup, and the launcher says so. When the OS refuses the shortcut, the launcher says so; on Linux it adds that on Wayland a desktop shortcut that runs `tinydash` works instead.

| Keys               | Action                                                                                                                         |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| Type               | Search                                                                                                                         |
| ↑ / ↓              | Select a result                                                                                                                |
| ↑ on the first row | With the search field empty, or filled by ↑: bring back the search before it                                                   |
| Enter              | Run the selected result's main action                                                                                          |
| Mod+Enter          | Run its second action: Show in Finder for apps and files, Pin for clipboard entries, snippets, quicklinks, emoji, and commands |

| Mod+K              | All actions for the result, plus Refresh, Center Launcher, Settings, and Quit TinyDash                                         |

| Mod+,              | Open Settings                                                                                                                  |
| Mod+P              | Start, pause, or resume the focus timer, or start its break, while the widgets show it                                         |

| Escape             | Close a dialog or the actions menu, dismiss a warning, or hide and return to the previous app                                  |

↑ brings back up to 50 searches that ran a result, newest first, each once. They are kept only until TinyDash quits, never saved. Editing a search brought back makes it a new one, and ↑ selects results again. A held ↑ stops at the first row; press it again to bring back a search.

Mod is Command on macOS and Control elsewhere. Moving the pointer onto a row selects it, and onto an item of the actions menu makes it the active one; a list that scrolls under a still pointer changes nothing. Clicking a row runs it; right-clicking it shows its actions, as Mod+K does. After a copy, the launcher hides and a short "Copied" message shows; it never takes focus from the app you return to, and the pointer passes through it. The launcher never takes focus from the app you were in, so that app has the keyboard again when the launcher hides. The launcher opens with an empty query in the exact center of the screen with the pointer, and hides when another app gets focus (optional). Drag the empty parts of the tab bar or the footer to move it; the search field keeps the keyboard. It opens at that spot again while the spot is on a screen. Center Launcher (Mod+K) or Center in Settings > General forgets the spot.

Command line: `tinydash` (show the launcher; if TinyDash already runs, toggle its launcher, as the shortcut does), `--settings` (open Settings), `--mode <category>` (show the launcher on a tab with an empty query: all, apps, files, clipboard, snippets, emoji, or system), `--background` or `--hidden` (start without a window, as at login), `--data-dir <folder>` (keep settings and data in that folder), `--help`. Run while TinyDash runs, the options act on the running TinyDash. Opening TinyDash again from Finder or Spotlight shows the launcher.

The tray (menu bar) icon shows the launcher on a click. Its menu (a right-click on macOS) has Open TinyDash, Settings…, and Quit TinyDash. With Open at login on, each start registers the running copy of TinyDash as the login item, so a login item of the Rust app or of an older copy points to it. A hotkey that cannot run shows why in a system notification. When the data of TinyDash 0.1 (`tinydash.sqlite3`) is still on disk, the launcher says where, so you can delete it.

## Categories

**All** mixes everything. An empty All shows pins (except pinned clipboard entries), then up to eight things you use often (not clipboard text or system commands). Each other tab searches one source. Its empty view, listed below, shows pins first and stops at 100 results. Settings > General shows, hides, and orders the tabs after All; a hidden tab's results still show in All, and Tab skips it. Each tab also has an "in All" switch: turned off, its search results and suggestions leave All (its pins stay on the empty All view, a snippet or quicklink keyword still answers there, and its tab still finds them), so a source such as emoji cannot fill the list. A tab is never both hidden and out of All: turning one switch off while the other is off turns the other on. A tab added in a later version joins the end of your list, shown.

| Category  | Finds                                                                                                                                                                                                                       | Empty view                  |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------- |
| Apps      | Installed apps (up to 5,000) by name, bundle name, or executable; each says what it is for (macOS, Linux) or where it is                                                                                                    | Apps, most used first       |
| Files     | Names of files and folders in the indexed folders                                                                                                                                                                           | Files you opened before     |
| Clipboard | Text, images, and file lists you copied                                                                                                                                                                                     | Newest first                |
| Snippets  | Saved snippets and quicklinks by name or keyword                                                                                                                                                                            | Snippets and quicklinks     |
| Emoji     | Name, :shortcode:, or keywords in chosen languages                                                                                                                                                                          | Most used, then the catalog |
| System    | Lock, Sleep, Restart, Shut Down, Log Out, Empty Trash, Open Trash, Sleep Displays, Toggle Dark Mode, Make Clipboard Plain Text, Clear Clipboard History, Clear Calculator History, System Settings, TinyDash Settings, Quit | All commands                |

An app that you install or remove shows the next time the launcher opens: TinyDash watches the app folders (on Linux, only directly inside them, as for files) and lists them all again when the launcher opens and the list is more than 15 minutes old.

Pin any app, file, clipboard entry, snippet, quicklink, emoji, or command from its actions (up to 100 pins). Pins stay at the top of the empty All view and of their category. A pinned clipboard entry is kept rather than launched, so it heads the Clipboard tab and is found by a search, but stays off the empty All view. A pin of an item that is hidden for now (a file outside the indexed folders, or a clipboard entry while history is off) is kept for when the item returns; when the list is full, the oldest such pin, or a pin of a result you hid, makes room for a new one.

Give any app, indexed file, snippet, quicklink, emoji, or command an alias from its actions (Add Alias): one word of up to 32 characters, such as `vsc` for Visual Studio Code. Typing the whole alias puts its result first, after any instant answer and above any name match; typing its start ranks the result like a name that starts with the query. This works in All (while its tab is in All) and in its tab. Each alias names one result. Change Alias shows the current one; saving it empty removes it. A row that carries typed text, such as `Jira: ABC-12`, has no Add Alias or Hide from Results: use the item's own row. Settings > Search lists them, with Remove. You can keep up to 500 aliases. An alias stays when its item is gone for now, such as an app being reinstalled, and goes with a deleted snippet or quicklink.

Give any app, indexed file, snippet, quicklink, emoji, or command a hotkey from its actions (Set Hotkey): keys that run its main action from any app, as Enter would, such as Control+Alt+S to open Safari or copy a snippet. The dialog records at once: press keys with Control, Alt, Command or Win, or a function key. They save when pressed. Escape, or leaving the launcher, stops recording, and Remove Hotkey removes it. The launcher shortcut and the hotkeys pause while you record, so pressing one records it. A hotkey must be free: not the launcher shortcut, not another result's hotkey (the launcher shortcut cannot take a hotkey's keys either), and not keys another app registered. A command that asks before it runs, such as Restart, has no hotkey. Settings > Search lists them, with Remove. You can keep up to 50 hotkeys. A hotkey goes with a deleted snippet or quicklink. Just after TinyDash starts, before it has found your apps and files, an app or file hotkey cannot run yet. A hotkey that cannot run does not bring up the launcher; a system notification says why. A hotkey that cannot register when TinyDash starts shows as a warning in the launcher.

Hide any app, file, snippet, quicklink, emoji, or command from its actions (Hide from Results): search leaves it out for good, and hiding a pinned item unpins it. Settings > Search lists hidden results, with Show Again (up to 500 hidden). A hidden result cannot be pinned; show it again first. Clipboard entries are deleted instead.

The details to the right of the results show the selected result large, with its kind and every action (click one to run it). A clipboard entry shows its whole text, its image, or its file paths; a snippet shows its text; an app, file, or folder shows where it is, its size (not for folders), and when it changed. Only apps TinyDash found and files it offered show their facts.

Usage ranking: each run of an app, file, emoji, snippet, quicklink, or system command raises it among similar matches (frequency up to 20 uses, recency by day). Copying a path or showing in Finder does not count. TinyDash remembers the 1,000 most recently used items. Results with equal scores keep the order in which their source lists them.

## Widgets

An empty All search shows widgets to the right of the results, in place of the details. Typing, or another tab, shows the details again. Settings > Widgets turns each widget on or off; with every widget off, the details stay.

- **Clocks** (on): local time and date, and up to three cities with their time and difference from local time. A city is any name that time zone answers know: `Tokyo`, `kl`, `Europe/London`, `pst`. Dates follow your regional formats, such as `January 5, 2026` or `5 January 2026`; times are 24-hour.
- **Disk space** (on): the free space on the disk of your home folder, and how full it is. Below 10% free, it warns. On macOS, free space counts purgeable files, as Finder does.
- **Focus timer** (off): Pomodoro focus sessions with a short break after each one, and a long break after the last session of a cycle. Mod+P, or the first button, starts, pauses, or resumes the timer, or starts the break that is due; Skip Break and Reset Timer are buttons too, and in the actions menu (Mod+K). A system notification says when a session or a break ends; on macOS the first one asks to allow notifications. Settings > Widgets sets the lengths: focus 1–120 minutes (25), short break 1–60 (5), long break 1–60 (15), and 1–8 sessions before a long break (4). New lengths count from the next phase. The timer runs while the launcher is hidden. It starts over when TinyDash quits, and when you turn it off.
- **Notepad** (off): one scratch note, kept on this computer in `tinydash.db`. Mod+J moves to the note; Mod+J, Escape, Tab, or Shift+Tab goes back to the search field. Other keys type in the note. It saves when you pause typing, leave the note, start a search, or hide the launcher, and says whether it is saved. A note over 10,000 characters is not saved until you shorten it. A note that cannot save keeps its text and tries again when you leave it or the widgets show again. If the note cannot be read, its card says why, and the other widgets still show.

Every All search with text ends with a web search on the chosen engine (Settings > Search), unless it is a web keyword followed by text, such as `yt lofi`. After it come up to three quicklinks whose URL or path has `{query}`, most used first, each filled with the whole text: `Jira: ABC-12`. They do not show after a keyword search (`g rust`, or a snippet or quicklink keyword), when snippets are out of All, for a hidden quicklink, or for a quicklink that already shows because the text matches its name. A path quicklink shows only for text that is a name.

- `?` lists every keyword, and nothing else: `=`, `time in`, `today`, `days until`, `pw`, `passphrase`, `pin`, the web keywords, and the keywords of your snippets and quicklinks, each with what it does and an example (up to 100 rows). `?` and a space followed by words lists the keywords whose row has a word that starts with each of them, so `? git` finds `gh, github`. Enter types the keyword into the search field, with a space when text follows it.
- Copying a calculator answer keeps it in the calculator history (expressions of up to 500 characters), newest first, up to 50, on this computer in `tinydash.db`. Copying the same expression again moves it to the top with its new result. Typing `=` in All lists the history, and `=` and a space followed by words lists the calculations whose expression or result holds them all (up to 20 rows). Enter copies the saved result and moves it to the top, Mod+Enter copies the expression, and Delete from History (Mod+Backspace) removes one. A calculation that starts with `=` and no space, such as `=5+3`, is answered like `5+3`. The System command Clear Calculator History deletes them all, after you confirm.
- The calculator reads percentages as people say them, in three shapes. In each, an amount is a number with an optional currency or unit after a space, such as `200`, `$30`, or `5 kg`, and a percentage is a number, such as `10%`. A word that the calculator reads as an operator, such as `per`, `to`, or `mod`, is not a unit.
- An amount and percentages to add or subtract: `30 + 20%` is 36 and `200 - 10%` is 180, because each percentage is of the value before it. Several apply in turn, so `200 - 10% - 5%` is 171.
- `10% of 200` is 20, `10% on 200` is 220, and `10% off 200` is 180. Each is one number in a calculation, so `10% of 200 + 50` is 70, `5 + 10% of 200` is 25, and `10% of 200 + 20% of 300` is 80. It can start the calculation, come after `(`, or come after a `+`, `-`, or `*` that follows an amount or a `)`, and it can end the calculation or come before `)`, `+`, `-`, `/`, or `*` (not the power `**`). Anywhere else, as in `pi + 10% of 200`, the calculation gives no answer.
- Questions, where each part is an amount: `20 is what % of 200` and `20 as a % of 200` are 10%, `180 is what % off 200` is 10%, `180 is what % on 150` is 20%, `50 to 75 is what %` is the change (50%), `3/20 is what %` and `0.35 as %` (also `to %` or `in %`) turn a ratio into a percentage, and `20 is 10% of what` is 200 (also `on what` and `off what`).
- Any other calculation with a percentage gives no answer, because the calculator would read it differently from you: `100 + 10% + 5`, `50 * 2 + 10%`, `10% + 20%`, `200 * 10%`, `200 / 10%`, and `400 / 10% of 200`. A percentage alone, such as `2e-3%`, and a remainder, such as `10 % 3`, still have answers.
- The words `plus`, `minus`, `times`, `multiplied by`, and `divided by` work as signs, `percent` works as `%`, the signs of typeset math `−`, `×`, and `÷` work as `-`, `*`, and `/`, and `€20` is 20 EUR.
- The calculator does not answer an expression longer than 500 characters, with more than 32 parentheses, with a lambda function, such as `(x: x + 1) 5`, `(x => x + 1) 5`, or `(\x.x + 1) 5`, or that defines a name, such as `a = 5; a * 2`. It also gives no answer when reading the expression would slow down search, as for deeply nested parentheses. Hyperbolic functions, such as `sinh(40)`, have no answer.
- The calculator does not answer a full date such as `2026-10-17` or a clock time such as `3pm` or `10:30`. A full date answers with its weekday. Shorter shapes, such as `12-3-4` or `2026-10`, stay subtractions.
- Dates are `today`, `tomorrow`, `yesterday`, `next friday`, `last monday`, `2026-12-25`, or a day and a month name in either order, with an optional year: `25 dec`, `December 25, 2026`, `sept 1st`. Without a year, the date is in this year (`feb 29`: the next leap year). Add or subtract days (`d`), weeks (`w`), months (`mo`), and years (`y`): `dec 25 - 3 weeks`. Phrases also work: `3 days from now`, `a week ago`, `2 weeks from tomorrow`, `2 months 3 days after 2026-06-05`, `28 days before mar 12`. Adding a month to the 31st gives the last day of a shorter month.
- `days until` (or `till`) and `days since` count the days from today; without a year, `days until dec 25` counts to the coming one and `days since dec 25` from the last one. `days between A and B` counts from one date to the other; without years, B is the first one after A, so `days between dec 20 and jan 5` is 16 days.
- Currency rates are off until you turn them on (Settings > Search, or Turn On Currency Rates on the answer that a currency query shows while they are off). TinyDash then uses the daily ECB table from Frankfurter, cached for offline use, and downloads it again at startup and when the launcher opens, when the table is older than 12 hours. After a download, the next one waits an hour unless you refresh, so a failing download does not run at each open. Only the table is downloaded. Turning rates off deletes the saved table.
- A currency is its ISO code in any case, such as `usd` or `MYR`, or a sign or name such as `$`, `€`, `£`, `¥`, `dollar`, or `euro`. The Chinese yuan is also `rmb`, `yuan`, or `renminbi`. The ECB table has 30 currencies. A query with any other, such as `100 twd to myr`, shows No exchange rate for TWD.
- Time zones accept IANA names (`America/New_York`), city names, countries, and common names (`pacific`, `pst`, `kl`). A wall time skipped by a clock change gives no answer; a repeated one gives two. The zone rules (IANA 2026c) come with TinyDash, as they did in the Rust app (2025b), so the computer's own zone files never change an answer.
- A color answer shows its RGB, HSL, and contrast on white, and Mod+K copies each form. A Unix time answer shows UTC and how long ago it was.
- Passwords: 8–64 characters from letters, digits, and symbols (at least one of each); 3–12 words from the EFF large wordlist, without its four hyphenated words, so the hyphens between words stay clear; 4–12 digits. Uses the OS random source.

## Clipboard history

Off until you turn it on (in the Clipboard tab or Settings). While on, TinyDash saves what you copy, newest first, up to the limit you choose (1–1000; pins do not count). Lowering the limit deletes the oldest entries at once, also while history is off. Turning history off hides saved entries, and their pins, but keeps them until you clear them; turning it on again shows them. While history is off, TinyDash reads nothing from the clipboard to save it.

- Text up to 16 KB. Images (up to 32, not counting pins, each at most 8 MB and 16 megapixels) and copied files (up to 64 paths, as references) are separate opt-ins.
- Copies marked secret by password managers are never read. On macOS, Passwords and Keychain Access mark nothing, so TinyDash skips a copy that it notices while that app is in front or was in front at its previous look. It looks twice a second, and when you open the launcher from that app. A copy made in the first half second after you switch to the app, if you also leave it in that time, can get through. A copy made in another app in the first half second after you leave it is also skipped.
- Enter copies the entry back in its original format and returns you to the previous app, ready to paste. Copying an entry again moves it to the top.
- Text is saved as plain text. A list of copied files also has Copy as Plain Text, which copies its paths, one per line.
- The System command Make Clipboard Plain Text puts the clipboard's text back without its formatting, such as fonts and links from a web page or a document, so it pastes as plain text. It works while history is off, and leaves a copy that its app marked secret as it is. With history on, the plain copy moves the entry to the top.
- Clear History deletes everything except pins, after you confirm. It is in the Clipboard tab (the footer button, or Mod+K), in Settings > Clipboard, and in the System command Clear Clipboard History. Data stays on this computer in `tinydash.db`, unencrypted.
- Linux saves text only.

## Snippets and quicklinks

Create them in Settings > Snippets and Settings > Quicklinks. An edit that you did not save stays while you visit another section.

- **Placeholders** work in both: `{query}` (the text you type after the keyword), `{clipboard}` (the text on the clipboard), `{date}` (`2026-10-11`), `{time}` (`09:05`), and `{datetime}`. They are filled in one pass, so a value that looks like a placeholder, such as typed text `{clipboard}`, stays as it is. Other text in braces stays too.
- **Snippet:** text. Enter fills the placeholders and copies the text. A snippet with a keyword and `{query}` takes the text typed after its keyword: with keyword `hi` and text `Hello {query},`, typing `hi Sam` copies `Hello Sam,`. Run from its own row, a placeholder with no value, such as `{query}`, is filled with nothing. Text that includes `{clipboard}` is copied as secret, so clipboard histories skip it, in case the clipboard held a password.
- **Quicklink:** an http, https, or mailto URL, or an absolute or `~` path. Placeholder values are encoded for a URL: with keyword `jira` and URL `https://jira.example.com/browse/{query}`, typing `jira ABC-12` opens that issue. In a path, the root (`~`, `/`, a drive, or a network share) comes from the quicklink, and a value must be a name: not a path, `.`, or `..`. `{clipboard}` is empty when the copy is secret: marked so by its app, as password managers do, or, on macOS, made in Passwords or Keychain Access.
- Limits: 500 snippets and quicklinks in all. A name has up to 100 characters, the text up to 32 KB, and the optional keyword is one word of up to 32 characters. Each keyword belongs to one snippet or quicklink. A keyword that is also a web keyword, such as `w`, shows your quicklink, or your snippet with `{query}`, first and the web search after it.

## Files

TinyDash indexes the names of files and folders in Desktop, Documents, and Downloads (change them in Settings > Search > Folders, as full paths such as `~/Projects`; up to 50 folders and 50 names to skip), up to 50,000 entries. It skips hidden entries (names that start with a dot, and items that macOS or Windows marks hidden, such as `~/Library` and `desktop.ini`), symbolic links, and folders named in the skip list (`node_modules`, `target` by default). It never reads file contents. On macOS, packages such as apps and photo libraries are listed as one item, without their contents. Changes are picked up the next time the launcher opens. On Linux, only changes directly inside the chosen folders are noticed at once (each watched folder uses one inotify watch from a per-user limit); deeper changes appear at the next full rescan, which starts when the launcher opens and the index is more than 15 minutes old. One word matches names; two or more words also match paths, so `project readme` finds `project/README.md`. A word with `/`, such as `project/readme`, also matches paths, on Windows too.

On macOS, **Also search with Spotlight** (Settings > Search, off by default) makes the Files tab also find names anywhere in your home folder, from the Spotlight index, below the results from your folders. It starts at two characters, skips hidden files, results you hid, and the folder names to skip, and adds up to 100 results. Spotlight finds only what it has indexed, and follows its own privacy settings. These results open, show in Finder, and copy their path; they cannot be pinned.

## Platform notes

- **macOS:** apps come from `/Applications`, `/System/Applications`, `~/Applications`, and the Apple utilities in CoreServices, up to four folders deep, plus Finder. An app is named by its file, as Finder names it; its bundle names and executable find it too, so `code` finds Visual Studio Code. A link to an app, such as Safari in `/Applications`, lists the app where it really is. Background helpers and TinyDash itself are not listed. App and file icons. Restart, Shut Down, Log Out, Empty Trash, and Toggle Dark Mode ask for Automation permission the first time. TinyDash has no Dock icon; the menu bar icon is off by default, so opening TinyDash again from Finder or Spotlight shows the launcher.
- **Windows:** Sleep Displays is named Turn Off Displays, and Open Trash and Empty Trash name the Recycle Bin. Toggle Dark Mode switches both apps and Windows, as Settings > Personalization > Colors does; a custom mix becomes one mode, the opposite of the apps' mode. The app list comes from the Windows Apps folder (`shell:AppsFolder`). Results use generic icons.
- **Linux:** apps come from the desktop entries that menus show (not NoDisplay or Hidden, meant for this desktop, and with their program installed), named in your language. Keywords and the program's name find an app too, and its generic name or comment says what it is for. Clipboard history saves text only. Linux has no clipboard change counter, so TinyDash compares the text: after history was off, it takes what the clipboard holds as already seen, and a copy made in the half second after you turn history on may not be saved. A copy of the same text as the last one is not saved again, also after you clear or delete it, and Make Clipboard Plain Text does not move the entry to the top. Results use generic icons. On GNOME, KDE, and Xfce, Restart, Shut Down, and Log Out go through the desktop's session manager, which asks apps to quit first; GNOME then shows its own dialog to restart or shut down. On other desktops, Restart and Shut Down use systemd, which closes apps without asking, and Log Out is not supported. So on Linux, their confirmation asks you to save your work first. System Settings supports GNOME, KDE, and Xfce. Toggle Dark Mode supports GNOME. Turn Off Displays (Sleep Displays) works on X11 and on KDE Plasma with Wayland.

## Changes from the Rust app

TinyDash 0.9.0 and earlier were a Rust and Tauri app. The Go app reads the same settings and data, with these differences:

- **Removed:** snippet expansion as you type, the Up Next, Weather, and clipboard card widgets, shell commands (`>`), the file permissions answer (`chmod`), update checks and installs, and the Files and Privacy sections of Settings. Their settings stay in `settings.json`.
- **Windows:** app IDs changed, so the pins, usage, aliases, and hotkeys of Windows apps reset once.
- **Ranking:** results with equal scores keep the order in which their source lists them.
- **Windows apps** are found by name only, not by executable, because the list comes from the Windows Apps folder.
- **Launcher position:** the Go app saves the spot in device-independent pixels. On Windows and Linux the Rust app saved physical pixels, so on a scaled display a spot that the Rust app saved opens elsewhere, or centered when it is off every screen.
- **Clock dates** are in English, in the order of your regional formats. The Rust app wrote them in the system's language.
- **A `settings.json` that holds `[]`** is moved to `settings.invalid.json`, as any other file that is not a JSON object.
