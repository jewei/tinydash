# Use TinyDash for the first time

This tutorial uses the desktop app. First [install a build](../how-to/install.md) or [start a development build](../how-to/build.md).

1. Open TinyDash. The launcher shows examples when All has no pinned items.
2. Click the search field and enter `12 * 8`. The result is `96`.
3. Press Enter. TinyDash copies `96` and hides the launcher. Paste it into a text editor to check the result. This step replaces the current clipboard value.
4. Press Control + Shift + Space to reopen TinyDash. On Wayland, use your configured desktop shortcut.
5. Enter `:coffee`. Use the arrow keys to select an emoji. The detail panel shows the selected result.
6. Select Apps. Enter the name of an installed application. Press Enter to open it.
7. Open Actions, then Appearance. Select Light, Dark, or Compact. TinyDash saves the choice.

You have used search, selection, copying, application launch, and appearance settings. Continue with the [feature catalog](../reference/features/README.md) or [keyboard shortcuts](../reference/keyboard-shortcuts.md).
